# Unity 2D Farming Game – Technical Showcase Repository

This repository contains a **limited, showcase-focused version** of a 2D mobile farming game developed in **Unity (C#)**.

The primary purpose of this repository is **to demonstrate my technical skills, code quality, and system architecture** during recruitment processes.  
It is **not** intended to represent the full production repository of the game.

---

## 🎮 Game Overview

The project is a **2D mobile farming simulation game**

Core gameplay concepts include:
- Tile-based farming (plowing, planting, growing, harvesting)
- Character-based interactions with energy consumption
- Resource management and progression systems
- Modular, system-oriented architecture for scalability
- Data-driven design using ScriptableObject definitions (code-level only)

The game is designed to be **online and scalable**, with future plans for social interaction and progression systems.

---

## 🧠 Architecture & Technical Focus

This repository intentionally highlights:
- Gameplay logic and systems (`Assets/Scripts`)
- Manager-based and modular architecture
- Interaction systems and state handling
- Clean, readable, and maintainable C# code practices

The focus is on **how systems are designed and implemented**, rather than on content.

## 🔒 Intellectual Property & Excluded Content

To protect the commercial value and intellectual property of the project, **a large portion of the game content is intentionally excluded** from this repository.

The following are **NOT included** and are ignored via `.gitignore`:

- All visual assets (sprites, tiles, UI, animations, VFX)
- Audio files (music, sound effects)
- ScriptableObject **data instances**
- Game economy values and balancing data
- Resources, Addressables, and StreamingAssets
- Backend configurations, API keys, and service files
- Build outputs and platform-specific binaries

As a result, **this project cannot be run or built as-is**.
